## 📌 Overview

This is the backend service for InterviewAI. It exposes RESTful APIs consumed by the React frontend. The backend handles user authentication, resume PDF parsing, AI-powered report generation via Google GenAI, and tailored resume PDF export via Puppeteer.

**Key Highlights:**
- JWT-based authentication with HTTP-only cookies and token blacklisting
- Resume PDF upload, parsing, and text extraction
- AI report generation with structured JSON output via Google GenAI
- Tailored resume PDF generation using Puppeteer
- Modular MVC architecture with separate controllers, services, and middleware

## 🚀 Getting Started

### 1. Clone Repository
```bash
git clone https://github.com/vaibhavkumar18/Interview-AI-Backend.git
cd Interview-AI-Backend
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Setup Environment Variables
Create a `.env` file in the root:
```env
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
GOOGLE_GENAI_API_KEY=your_google_genai_key
FRONTEND_URL=http://localhost:5173
```

### 4. Run Backend
```bash
# Development
npm run dev

# Production
npm start
```

## 📡 API Reference

### Auth Routes
| Method | Endpoint | Description | Auth Required |
|---|---|---|---|
| POST | /api/auth/register | Register new user | ❌ |
| POST | /api/auth/login | Login user | ❌ |
| POST | /api/auth/logout | Logout user | ✅ |
| GET | /api/auth/get-me | Get current user | ✅ |

### Interview Routes
| Method | Endpoint | Description | Auth Required |
|---|---|---|---|
| POST | /api/interview/generate | Generate AI interview report | ✅ |
| GET | /api/interview/reports | Get all reports for user | ✅ |
| GET | /api/interview/report/:id | Get single report by ID | ✅ |
| GET | /api/interview/resume/:id | Download generated resume PDF | ✅ |

## 🔐 How Authentication Works

1. User registers or logs in
2. Backend signs a JWT and stores it as an **HTTP-only cookie**
3. All protected routes verify JWT via `auth.middleware`
4. On logout, token is added to a **blacklist collection** in MongoDB
5. Blacklisted tokens are rejected on every subsequent request

---

## 🤖 How AI Report Generation Works

1. User uploads resume PDF and pastes job description
2. Backend extracts resume text using **pdf-parse**
3. Resume text + job description + self description sent to **Google GenAI**
4. GenAI returns structured JSON validated by **Zod schema**
5. Report includes:
   - ✅ Match Score
   - ✅ Technical Interview Questions
   - ✅ Behavioral Interview Questions
   - ✅ Skill Gap Analysis
   - ✅ Preparation Roadmap
6. Report saved to MongoDB and returned to frontend
7. User can download a **tailored resume PDF** generated by Puppeteer
